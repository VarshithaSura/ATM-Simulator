# ATM Simulator

A simple ATM Simulator built using HTML, CSS, and JavaScript.

## Features
- Check available balance
- Deposit money
- Withdraw money
- Validate entered amounts
- Prevent withdrawals exceeding the available balance
- Display transaction messages dynamically

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
